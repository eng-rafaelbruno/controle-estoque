# Controle de Estoque

Aplicação CRUD desenvolvida em Python para gerenciamento de estoque por meio de uma interface de linha de comando (CLI).

## Funcionalidades

- Adicionar produtos
- Listar produtos cadastrados
- Atualizar quantidade de produtos
- Remover produtos
- Menu interativo no terminal

## Tecnologias

- Python 3

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/eng-rafaelbruno/controle-estoque.git
```

2. Acesse a pasta do projeto:

```bash
cd controle-estoque
```

3. Execute o programa:

```bash
python estoque_produtos.py
```
