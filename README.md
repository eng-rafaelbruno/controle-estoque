# 📦 Controle de Estoque

Aplicação CRUD desenvolvida em Python para gerenciamento de estoque por meio de uma interface de linha de comando (CLI).

## 📖 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Python, como funções, estruturas de dados, condicionais e laços de repetição.

A aplicação permite gerenciar um estoque de produtos diretamente pelo terminal, possibilitando cadastrar, listar, atualizar e remover produtos de forma simples e organizada.

## 🚀 Funcionalidades

- ✅ Cadastro de produtos
- ✅ Listagem de produtos
- ✅ Atualização da quantidade em estoque
- ✅ Remoção de produtos
- ✅ Validação para impedir produtos duplicados
- ✅ Organização automática da listagem em ordem alfabética
- ✅ Interface interativa via terminal (CLI)

## 🛠️ Tecnologias utilizadas

- Python 3

## 🧠 Conceitos aplicados

- CRUD (Create, Read, Update e Delete)

## ▶️ Como executar

### Pré-requisitos

- Python 3.10 ou superior instalado.

### Clone o repositório

```bash
git clone https://github.com/eng-rafaelbruno/controle-estoque.git
```

### Acesse a pasta

```bash
cd controle-estoque
```

### Execute o programa

```bash
python estoque_produtos.py
```
